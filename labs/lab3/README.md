## Параметри варіанта 2

**Завдання 1 - кусочна функція** (`branching_logic.py`):

    f(x) = cos(x^2) + 1,   x < -1
    f(x) = x^3 + 2x,       -1 <= x <= 1
    f(x) = cbrt(x - 1),    x > 1

Гілка вибирається двома способами: `if-elif-else` і тернарний вираз.

**Завдання 2 - табулювання та ряд** (`series_tabulation.py`):

| Параметр | Значення |
|---|---|
| Відрізок табулювання | [-3, 3] |
| Крок h | 0.25 |
| Кількість кроків N | 24 (25 вузлів) |
| Ряд | sin x = sum (-1)^k x^(2k+1) / (2k+1)! |
| Рекурентність | a_k = a_(k-1) * (-x^2) / (2k(2k+1)), a_0 = x |
| Точність | eps = 1e-7 |
| Еталон | math.sin(x) |
