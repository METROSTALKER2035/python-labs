## Параметри варіанта 2

| Параметр | Значення |
|---|---|
| Утиліта | Детектор порожніх папок (`empty_dir_cleaner`) |
| Параметри `sys.argv` | `--path <dir> --dry-run` |
| Специфікація | Рекурсивний пошук директорій без файлів; імітація безпечного видалення |

Каталог вважається порожнім, якщо в усьому його піддереві немає файлів; символічні
посилання рахуються файлами, за ними сканер не йде. Сторінка завдання не містить
вхідних даних для варіанта 2, тому `test_sandbox` створено за командами зі сторінки
(без порожніх каталогів), а порожні каталоги для перевірки додаються командами
з розділу «Запуск».

## Структура

```
lab08/
├── .vscode/
│   └── launch.json            # Конфігурація налагоджувача з передачею CLI-аргументів
├── .gitignore                 # Правила виключення тимчасових файлів
├── cli_main.py                # Головний модуль-точка входу (CLI Dispatcher)
├── fs_toolkit/                # Користувацький пакет інженерних системних утиліт
│   ├── __init__.py            # Ініціалізація пакета та експорт публічного API
│   ├── scanner.py             # Модуль сканування та аналізу метаданих файлів
│   └── reporter.py            # Модуль форматування та табличного виведення
├── test_sandbox/              # Тестова пісочниця з файлами різного розміру та типу
│   ├── system.log             # Тестовий лог-файл (розмір > 0)
│   ├── firmware.bin           # Тестовий бінарний файл
│   ├── config.json            # Конфігураційний файл
│   └── nested_dir/            # Вкладена директорія для перевірки рекурсії
│       └── app_dump.log       # Вкладений лог-файл
└── README.md                  # Звітний опис виконання індивідуального варіанта
```

## Запуск

```
conda activate ce_lab_env
python cli_main.py --help

python cli_main.py --path ./test_sandbox --dry-run     # лише симуляція
```

У пісочниці з сторінки завдання порожніх каталогів немає, тому для перевірки їх
створюють звичайними командами `mkdir` (однаково працюють у PowerShell і bash):

```
mkdir test_sandbox/empty_dir
mkdir test_sandbox/.cache_old
mkdir test_sandbox/nested_dir/empty_child
mkdir test_sandbox/reports
mkdir test_sandbox/reports/2025
mkdir test_sandbox/reports/2025/Q1

python cli_main.py --path ./test_sandbox --dry-run     # знайдено 6 порожніх каталогів
python cli_main.py --path ./test_sandbox               # справжнє видалення
```

**Увага:** без `--dry-run` порожні каталоги видаляються безповоротно (лише через
`Path.rmdir`, файли не зачіпаються).

## Коди завершення

У PowerShell код останньої команди показує `$LASTEXITCODE`, у bash - `echo $?`.

| Код | Значення |
|---|---|
| 0 | Успіх (включно з показом довідки) |
| 1 | Синтаксична помилка командного рядка (невідомий параметр, немає значення чи `--path`) |
| 2 | Помилка аргументів (шлях не існує або не є каталогом) |
| 3 | Критичний збій |
