## Параметри варіанта 2

| Параметр | Значення |
|---|---|
| Вузол / підсистема | Модуль швидкісного АЦП (ADC) |
| Контрольовані параметри та обмеження | Частота вибірки: 1 ... 100 МГц; вхідна напруга: -2.5 ... +2.5 В |
| Класи винятків | `ADCValidationError`, `SamplingRateError`, `InputOverloadError` |

Ієрархія (`custom_exceptions.py`): `ADCValidationError(Exception)` - базовий клас із полями
`error_code` і `timestamp` (код 1000); `SamplingRateError` (код 1001) зберігає
`sampling_rate_mhz`, `min_mhz`, `max_mhz`; `InputOverloadError` (код 1002) зберігає
`input_voltage`, `min_v`, `max_v`. Помилку перетворення типу параметра базовий клас
передає з кодом 1003 через `raise ... from ...`.

Результат: тестовий стенд із 9 наборів (2 успішні, 7 нештатних ситуацій) демонструє
`try-except-else-finally`, перехід у безпечний режим Fail-Safe та розрахунок
`P_recovery = N_handled / N_total_faults` (100.00%). Сторінка завдання не містить
тестових наборів для варіанта 2, тому їх складено самостійно.
