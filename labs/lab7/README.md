## Параметри варіанта 2

| Параметр | Значення |
|---|---|
| Варіативна функція | калькулятор метрик надійності вузлів, дані вузлів приходять через `*args` |
| Lambda-сортування | `CPU_Usage` за спаданням, а за рівних значень `RAM_Free` за зростанням (`sorted()` з lambda-ключем) |
| Рекурсивний алгоритм | сортування злиттям (Merge Sort) з обліком глибини стека (`DepthTracker`), порівняння з ітеративним аналогом та `sorted()` |
| Аналітика | `T(n) = 2·T(n/2) + Θ(n)`, за основною теоремою `T(n) = Θ(n log n)` |
