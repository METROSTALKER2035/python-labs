## Параметри варіанта 2

**Завдання 1 - вектор** (`vector_algorithms.py`):

| Параметр | Значення |
|---|---|
| Довжина вектора N | 20 |
| Діапазон значень | [0, 100] |
| Фільтрація | залишити елементи, кратні 5 (list comprehension) |
| Сортування | метод бульбашки (Bubble Sort) без `.sort()` |

**Завдання 2 - матриця** (`matrix_operations.py`):

| Параметр | Значення |
|---|---|
| Розмір матриці A | 3 x 5 |
| Множник | вектор-стовпець X з R^5 |
| Результат | Y = A * X (три елементи), мінімум кожного рядка A |

**Завдання 3 - кортеж:** незмінний кортеж `CONFIG = (N, M, K, X_MIN, X_MAX) = (20, 3, 5, 0, 100)`
розпаковується паралельним присвоюванням. Кортеж визначено у `vector_algorithms.py`
і імпортується в `matrix_operations.py`.

Додатково реалізовано транспонування, добуток матриць із перевіркою розмірів і
пошук сідлових точок.
