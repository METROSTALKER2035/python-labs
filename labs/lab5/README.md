## Параметри варіанта 2

| Параметр | Значення |
|---|---|
| Тип журналу | Системний журнал Linux Syslog |
| Формат запису | `Month Day HH:MM:SS Hostname Daemon_Name[PID]: SEVERITY: Message` |
| Рівні важливості | `INFO` або `ERR` |
| Завдання | виділити процеси із записами `ERR` і згрупувати записи за `Daemon_Name` |

Регулярний вираз `LOG_PATTERN` містить іменовані групи `month`, `day`, `time`, `hostname`,
`daemon`, `pid`, `severity`, `message` та прив'язку `^...$`.

Валідація: місяць із 12 назв, день відповідно до місяця, час 00:00:00..23:59:59,
PID 1..4194304, коректне ім'я вузла. З повідомлень ERR додатково витягуються адреси IPv4
(кожен октет 0..255).

Сторінка завдання не містить зразка даних для варіанта 2, тому вхідний файл
`input_logs.txt` складено самостійно: коректні, пошкоджені та невалідні рядки.
