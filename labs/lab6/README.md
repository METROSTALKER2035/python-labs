## Параметри варіанта 2

| Параметр | Значення |
|---|---|
| Предметна область | Облікові записи Active Directory |
| Структура запису | `Username -> {Email, Department, Roles_Set, Is_Active}` |
| Аудит множин | права користувача проти шаблону відділу (`frozenset`): надлишкові `A \ B`, відсутні `B \ A`, індекс Жаккара `J(A, B) = |A ∩ B| / |A ∪ B|` |
| Counter | кількість подій входу за користувачем, `most_common(3)` |
| Індекс | `роль -> список користувачів` (dict comprehension) |

Сторінка завдання не містить вхідних даних для варіанта 2, тому базу з шести облікових
записів, шаблони прав і потік із 42 подій входу складено самостійно.
