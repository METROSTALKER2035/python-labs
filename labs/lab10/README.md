## Параметри варіанта 2

| Параметр | Значення |
|---|---|
| Предметна область та вхідний CSV-файл | Моніторинг серверів ЦОД (`servers.csv`) |
| Критерій фільтрації та розрахунку | Завантаження CPU > 80%; підрахунок середнього обсягу вільної RAM |
| Магічна сигнатура BIN-файлу | `0x4E4F4445` (ASCII: `'NODE'`) |

Конвеєр у `telemetry_pipeline.py` складається з трьох етапів: відбір рядків CSV за
критерієм (`csv.DictReader`, `csv.DictWriter`), перевірка сигнатури й розміру
корисного блоку BIN-файлу (`seek()` і `tell()`) та збереження зведеного стану
в `station_snapshot.json` (`json.dump`, `indent=4`). Сторінка завдання не містить
вхідних даних для варіанта 2, тому `servers.csv` (10 рядків із колонками
`Timestamp`, `Server_ID`, `CPU_Load_Pct`, `RAM_Free_GB`) і `firmware_sample.bin` (14 байтів:
сигнатура `NODE`, версія 1.4, 8 байтів корисного блоку) складено самостійно.
