## Параметри варіанта 2

| Параметр | Значення |
|---|---|
| Базовий клас | Процесорне ядро `CPUKernel` (частота, IPC) |
| Похідний клас | Векторний прискорювач `SIMDKernel` (розрядність) |
| Оператор `+` | Сумування продуктивності ядер (MFLOPS) |
| Оператор `<` | За тактовою частотою |

Продуктивність ядра розраховується як `P = f[ГГц] · 1000 · IPC` для `CPUKernel` і
`P = f[ГГц] · 1000 · IPC · L` для `SIMDKernel`, де `L = розрядність / 64` – кількість смуг FP64.
Оператор `+` повертає нове ядро з частотою `max(f1, f2)` та продуктивністю `P1 + P2`, буфери
вимірів об'єднуються. Сторінка завдання не містить тестових даних для варіанта 2, тому
значення в `test_bench.py` (частоти, IPC, виміри MFLOPS) і порогові значення валідації
(частота не нижча за 0.5 ГГц, IPC додатний, розрядність SIMD 128 / 256 / 512 біт) обрано самостійно.
